# dev-test

A simple development environment test project built inside **WSL 2 (Ubuntu)** with **VS Code** and synchronized to GitHub via SSH.

## Setup & Verification

- **OS:** Windows 10/11 with WSL 2 (Ubuntu)
- **Language:** Python 3
- **Authentication:** SSH (Ed25519)

### Running the Script

To run the script locally inside the WSL environment:

```bash
python3 hello.py
```
